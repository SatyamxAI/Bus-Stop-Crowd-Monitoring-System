# Bus Stop Crowd Monitoring

## Objective

Estimate crowd density and waiting patterns at bus stops using AI-powered computer vision.

---

## Features

- Person Detection
- Multi Object Tracking
- Crowd Counting
- Crowd Density Estimation
- Waiting Time Estimation
- Congestion Alerts
- Evidence Snapshots
- CSV Reports
- Annotated Output Video

---

## Tech Stack

- Python
- OpenCV
- YOLOv8
- ByteTrack
- Pandas
- NumPy
